# Cauldron Collection

Adds cauldrons made of many materials: woods (acacia, birch, dark oak, jungle, oak, spruce),
gold, diamond, cobblestone, brick, obsidian, glass, stone, granite, diorite and andesite
(and their polished variants). They work like the vanilla cauldron.

## Origin

Cauldron Collection is a port of **More Cauldrons** by Mrbysco (Minecraft 1.16.5, Forge) to
modern Minecraft. Licensed under the MIT License (see `LICENSE` and `NOTICE`). Cauldron
Collection is unofficial and is not affiliated with or endorsed by the original author.

## Supported versions

| Minecraft | Forge | NeoForge | Fabric | Java |
|---|---|---|---|---|
| 1.21.1 | 52.1.21 | 21.1.259 | loader 0.19.5 + Fabric API | 21 |
| 1.20.1 | 47.4.23 | - | - | 17 |
| 26.1.2 | 64.1.4 | 26.1.2.78 | loader 0.19.5 + Fabric API | 25 |
| 26.2 | 65.1.4 | 26.2.0.57 | loader 0.19.5 + Fabric API | 25 |
| 26.3 | 66.0.11 | 26.3.0.26-beta | loader 0.19.5 + Fabric API | 25 |

Each Minecraft version and loader lives in its own branch
(`minecraft/<mc>/<loader>-<version>/main`). The mod is required on both client and server;
no other mods are needed (Fabric builds need Fabric API).
